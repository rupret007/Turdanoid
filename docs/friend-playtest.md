# A short arcade playtest

Use either band's published arcade. About ten minutes is enough for an initial
impression. These are questions for friends, not an automated acceptance claim.

1. Pick any game and start without instructions from us. Was the first action
   obvious? Describe anything you had to guess.
2. Open **Your progress**, choose a goal that interests you, and follow its game
   link. Is the requirement clear, and does the displayed progress make sense?
3. Finish a short run, round or match. Check the outcome and any earned goal.
   Use Play again. Does it return to the mode you expected?
4. Return to the hub. Check Recent results and Game records. Are the two views
   understandable? Refresh once and check that nothing was counted twice.
5. Try Share result/score or Save image. On a phone, optionally try the actual
   operating-system share sheet and rotate the screen. Report confusing labels,
   clipped controls or a result card that misrepresents what happened.

Tell us:

- Which game would you choose to play again, and why?
- What interrupted the fun or made you hesitate?
- Did goals/progress add something useful? Which target would you choose next?

For a problem, include the site URL, game, browser/device and steps to repeat it.
Progress stays in that browser on that site; it does not sync across devices or
between the two band sites. No daily visit is required.

This checklist is prepared for manual sharing; no invitations have been sent.
